# 心不全治療薬まとめ (HFrEF / HFpEF)

!!! warning "免責"
    本ページは個人の学習メモです。実投与量や適応は **最新の JCS/JHFS 心不全ガイドライン・添付文書** をご確認ください。

## Fantastic Four — 色で覚える

HFrEF の慢性期は **4本柱を できるだけ早期に・並行して・忍容範囲で最大量**。

<span class="rx ff-1">① ARNI / ACE-I / ARB</span>
<span class="rx ff-2">② β遮断薬</span>
<span class="rx ff-3">③ MRA</span>
<span class="rx ff-4">④ SGLT2i</span>

!!! mnemonic "覚え方 — 『ABMS』"
    **A**RNI（or ACE-I/ARB） / **B**eta blocker / **M**RA / **S**GLT2i。
    順番に追加するのではなく **4本柱を低用量で同時に立ち上げる** のが現代の推奨。

## 分類のおさらい

| 区分 | LVEF | キーワード |
|---|---|---|
| HFrEF | ≤40% | Fantastic Four のエビデンス確立 |
| HFmrEF | 41–49% | HFrEF寄りに準じた治療を検討 |
| HFpEF | ≥50% | <span class="rx ff-4">SGLT2i</span> がブレークスルー |

## HFrEF — Fantastic Four 詳細

### ① ARNI / ACE-I / ARB { .rx-card .arni }

<span class="rx ff-1">①</span> <span class="rx arni">ARNI</span> <span class="rx acei">ACE-I</span> <span class="rx arb">ARB</span>

| 薬 | 用量目安 | コメント |
|---|---|---|
| サクビトリル/バルサルタン (エンレスト) | 50 → 100 → 200 mg × 2/日 | PARADIGM-HF で ACE-I 上回り第一選択 |
| エナラプリル (レニベース) | 2.5 → 10 mg × 2/日 | ACE-I の歴史的ベンチマーク |
| カンデサルタン (ブロプレス) | 4 → 32 mg/日 | ACE-I 不耐 (空咳) で代替 |

!!! pearl "切替の手順"
    ACE-I → ARNI は <span class="key-num">36時間</span> あけて切替（血管浮腫リスク）。  
    ARB → ARNI は washout 不要。

### ② β遮断薬 { .rx-card .beta }

<span class="rx ff-2">②</span> <span class="rx beta">β遮断</span>

- **エビデンスのある薬を選ぶ**: カルベジロール / ビソプロロール / メトプロロール徐放（本邦未承認剤型あり）
- 用量目安: カルベジロール 1.25 → 20 mg/日（分2）、ビソプロロール 0.625 → 5 mg/日
- **急性非代償期（うっ血/低灌流）では新規導入しない**。代償化してから低用量開始 → 2週ごとに漸増。

!!! pitfall "中止は控える"
    急性期も **既存内服は基本継続**（中断で再悪化）。耐えられない時は減量で対応。

### ③ MRA { .rx-card .mra }

<span class="rx ff-3">③</span> <span class="rx mra">MRA</span>

- スピロノラクトン 25–50 mg、エプレレノン 25–50 mg
- 高K (>5.0) / eGFR<30 で慎重
- **K と Cr の定期チェック必須**（開始 1, 4, 8週、その後 3か月毎目安）

### ④ SGLT2 阻害薬 { .rx-card .sglt2 }

<span class="rx ff-4">④</span> <span class="rx sglt2">SGLT2i</span>

- ダパグリフロジン <span class="key-num">10 mg</span>、エンパグリフロジン <span class="key-num">10 mg</span>
- DAPA-HF / EMPEROR-Reduced で **糖尿病の有無を問わず** HFrEF 予後改善
- **HFpEF にも有効** (EMPEROR-Preserved, DELIVER)

!!! pitfall "SGLT2i の sick day rule"
    脱水・絶食・周術期は **休薬**（ケトアシドーシスリスク）。
    性器感染・軽度の体液量減少にも注意。

### 補助薬

| 薬 | 適応 |
|---|---|
| 利尿薬（ループ / サイアザイド） | うっ血の症状緩和。予後改善は限定的 |
| イバブラジン (コララン) | 洞調律 + HR≥75 + β最大量でも残る頻脈 |
| ベルイシグアト (ベリキューボ) | sGC刺激薬。直近の悪化例の予後改善 (VICTORIA) |
| 鉄補充（カルボキシマルトース鉄） | 鉄欠乏 (フェリチン<100 or 100–299 + TSAT<20%) で QOL↑ |
| ジゴキシン | AF合併・症状残存例の補助 |

## 4剤同時導入のコツ（patient-tailored）

!!! pearl "状況別の優先順位"
    - **頻脈寄り** → <span class="rx ff-2">β</span> を早く  
    - **うっ血強い** → 利尿 + <span class="rx ff-4">SGLT2i</span> を早く  
    - **低血圧寄り** → <span class="rx ff-1">ARNI</span> を慎重、<span class="rx ff-3">MRA</span>・<span class="rx ff-4">SGLT2i</span> から  
    - **腎/K 余裕あり** → <span class="rx ff-3">MRA</span> を早く

## HFpEF / HFmrEF

| 推奨度 | 介入 |
|---|---|
| **Class I** | <span class="rx ff-4">SGLT2i</span>、合併症（HT/AF/CKD/肥満）の最適化、適切な利尿 |
| Class IIa | <span class="rx ff-3">MRA</span>（特に LVEF 50%付近）、<span class="rx ff-1">ARNI</span>（PARAGON-HF サブ解析） |
| その他 | AF の rhythm control / アブレーション、心臓リハ |

## 急性心不全 — Forrester / Nohria 分類で色分け

うっ血 (Wet/Dry) × 末梢循環 (Warm/Cold) で見る。

<div class="quad" markdown>

<div class="q wd" markdown>
**Warm & Dry** <span class="label">代償</span>

慢性期治療最適化。  
新規介入は不要なことが多い。
</div>

<div class="q ww" markdown>
**Warm & Wet** <span class="label">最多</span>

利尿薬（ループ iv）+ 血管拡張薬（ニトロ等）。  
急性肺水腫で血圧高めならニトロ iv が決め手。
</div>

<div class="q cd" markdown>
**Cold & Dry** <span class="label">低灌流</span>

容量負荷を試す（注意深く）+ 強心薬（ドブタミン / PDE3）。  
原因（不整脈・虚血）の精査も忘れない。
</div>

<div class="q cw" markdown>
**Cold & Wet** <span class="label">最重症</span>

強心薬 + 利尿薬、効果不十分なら **機械補助** (IABP / Impella / VA-ECMO)。  
ショックなら昇圧（ノルアド）。
</div>

</div>

### 主な薬剤

| 薬 | 使いどころ |
|---|---|
| <span class="rx loop">ループ</span> フロセミド iv | 第一選択の利尿。経口の 1–2.5倍量を iv、持続点滴の選択肢も |
| トルバプタン (サムスカ) | 低Na血症合併・ループ抵抗性 |
| ニトログリセリン / 硝酸イソソルビド iv | 急性肺水腫、特に **血圧高めのうっ血** |
| カルペリチド (ハンプ) | 利尿 + 血管拡張、本邦で多用 |
| ドブタミン / PDE3 阻害薬 (ミルリノン / オルプリノン) | Cold（低灌流）。**短期使用** |
| ノルアドレナリン | ショック合併（cardiogenic shock） |
| 機械補助 (IABP / Impella / VA-ECMO) | 薬剤抵抗性の cardiogenic shock |

!!! pitfall "ループ抵抗性チェックリスト"
    1. 服薬・塩分摂取のコンプライアンス
    2. 経口 → iv への切替（吸収不全）
    3. 投与回数を増やす（半減期が短い）
    4. **サイアザイド追加**（シーケンシャル ネフロン ブロック）
    5. トルバプタン、アセタゾラミド (ADVOR で追加効果)
    6. 限外濾過

## モニタリング

| 項目 | 頻度の目安 |
|---|---|
| 体重 | 毎日（自宅） |
| 血圧・脈拍 | 毎日 |
| Na/K/Cr | 開始時 + 1, 4, 8週、その後 3か月毎 |
| NT-proBNP / BNP | 適宜（トレンドが大事） |
| 心エコー LVEF | 3–6か月毎、治療反応評価 |

## 急性期で気をつけるピットフォール

!!! pitfall "してはいけない"
    - β遮断薬を **急性期にいきなり開始しない**（既存内服は継続）
    - **NSAIDs は HF悪化** → 鎮痛は別の選択肢で
    - **造影剤・大量輸液** で容易にうっ血悪化
    - 低Na血症は **希釈性が多い** → 水制限が基本、トルバプタン検討
