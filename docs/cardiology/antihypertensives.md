# 降圧薬まとめ

!!! warning "免責"
    本ページは個人の学習メモです。投与量・適応・禁忌は最新の **添付文書・ガイドライン (JSH2019 ほか)** を必ずご確認ください。

## クラス早見（色で覚える）

<span class="rx acei">ACE-I</span> <span class="rx arb">ARB</span> <span class="rx arni">ARNI</span> RAS阻害（**紫系**）
<span class="rx ca-dhp">Ca DHP</span> <span class="rx ca-ndhp">Ca 非DHP</span> Ca拮抗（**緑系**）
<span class="rx beta">β遮断</span> 心拍を落とす（**橙**）
<span class="rx thiazide">サイアザイド</span> <span class="rx loop">ループ</span> 利尿（**青系**）
<span class="rx mra">MRA</span> ミネラルコルチコイド受容体（**山吹**）
<span class="rx alpha">α遮断</span> 末梢血管（**薄紫**）
<span class="rx sglt2">SGLT2i</span> 心腎代謝（**桃**）

## 全体方針（ざっくり）

- **First-line**: <span class="rx acei">ACE-I</span> / <span class="rx arb">ARB</span> / <span class="rx ca-dhp">Ca DHP</span> / <span class="rx thiazide">サイアザイド</span>
- <span class="rx beta">β</span> は単独 first-line からは外れたが、**虚血・心不全・頻拍合併** で強い適応
- **単剤よりも 2剤少量併用** のほうが副作用少なく降圧効果大
- 降圧目標: 75歳未満および合併症あり <span class="key-num">130/80</span>、75歳以上 <span class="key-num">140/90</span>（JSH2019）

## 1. RAS阻害薬（**紫**）

### ACE阻害薬 (ACE-I) { .rx-card .acei }

<span class="rx acei">ACE-I</span>

| 項目 | 内容 |
|---|---|
| 機序 | アンジオテンシン I → II の変換阻害、ブラジキニン分解抑制 |
| 代表薬 | エナラプリル (レニベース) / イミダプリル (タナトリル) / ペリンドプリル (コバシル) |
| 強い適応 | 心不全 (HFrEF)、CKD（蛋白尿あり）、心筋梗塞後、糖尿病 |
| 注意 | **空咳** (10–30%、ブラジキニン由来) / 高K血症 / Cr上昇 / 血管浮腫 |
| 禁忌 | **妊婦**、両側腎動脈狭窄、血管浮腫の既往 |

!!! pearl "クリニカルパール — Cr 30% ルール"
    ACE-I 開始 1–2 週で **Cr が <span class="key-num">30%</span> 以内** の上昇は許容（むしろ腎保護効果が働いているサイン）。それ以上の上昇や K↑↑ なら中止検討。

!!! mnemonic "覚え方 — 空咳は B（Bradykinin）"
    ACE は **Br**adykinin を分解する。阻害すれば Br たまる → 気道刺激 → **空咳**。
    だから ARB（受容体阻害だけ）では空咳が起きない。

### ARB（アンジオテンシン受容体拮抗薬） { .rx-card .arb }

<span class="rx arb">ARB</span>

| 項目 | 内容 |
|---|---|
| 機序 | AT1 受容体選択的拮抗 |
| 代表薬 | ロサルタン (ニューロタン) / カンデサルタン (ブロプレス) / オルメサルタン (オルメテック) / アジルサルタン (アジルバ) / テルミサルタン (ミカルディス) |
| 強い適応 | ACE-I と同じ（心不全・CKD・DM・MI後）、ACE-I 空咳例の代替 |
| 注意 | 高K血症 / Cr上昇 / まれに血管浮腫（ACE-I より低頻度） |
| 禁忌 | **妊婦**、両側腎動脈狭窄 |

!!! pitfall "ACE-I と ARB の併用は基本 NG"
    ONTARGET 試験以来、ARB + ACE-I 併用は **腎機能悪化・K上昇・低血圧** リスクが上回り推奨されない。

### ARNI（アンジオテンシン受容体・ネプリライシン阻害薬） { .rx-card .arni }

<span class="rx arni">ARNI</span>

| 項目 | 内容 |
|---|---|
| 代表薬 | サクビトリル/バルサルタン (エンレスト) |
| 適応 | HFrEF（ACE-I/ARB の代替として優位、PARADIGM-HF）、本邦では高血圧にも適応 |
| 注意 | ACE-I からは <span class="key-num">36時間</span> あけて切替（血管浮腫リスク） / 高K / 低血圧 |

!!! mnemonic "覚え方 — エンレスト切替のルール"
    **ACE-I → ARNI = 36時間 washout**。  
    **ARB → ARNI = washout 不要**（受容体だけ抑えていたので浮腫リスクが残らない）。

## 2. Ca拮抗薬（**緑系**）

### ジヒドロピリジン系 (DHP) { .rx-card .ca-dhp }

<span class="rx ca-dhp">Ca DHP</span>

| 項目 | 内容 |
|---|---|
| 機序 | 血管平滑筋 L型 Ca チャネル阻害 → 末梢血管拡張 |
| 代表薬 | アムロジピン (ノルバスク/アムロジン) / ニフェジピン CR (アダラート CR) / シルニジピン (アテレック) / アゼルニジピン (カルブロック) |
| 強い適応 | 高齢者高血圧、孤立性収縮期高血圧、脳血管障害後、狭心症 |
| 注意 | 下腿浮腫（用量依存）/ 動悸 / 歯肉肥厚 / ほてり |

!!! pearl "L+N / L+T 型 Ca 拮抗薬"
    **シ**ルニジピン (L+N型) / **ア**ゼルニジピン (L+T型) は **反射性頻脈が少ない**。タンパク尿減少効果も。
    覚え方: 「**シ**ュッと **ア**ガらない」（脈が）。

### 非ジヒドロピリジン系 { .rx-card .ca-ndhp }

<span class="rx ca-ndhp">Ca 非DHP</span>

| 項目 | 内容 |
|---|---|
| 代表薬 | ベラパミル (ワソラン) / ジルチアゼム (ヘルベッサー) |
| 機序 | 心筋・洞房結節への作用も強い → 心拍数↓ |
| 適応 | 上室性頻拍、HFpEF の rate control、冠攣縮性狭心症 |

!!! pitfall "禁忌 — HFrEF と β併用"
    非DHP は陰性変力 → **HFrEF では禁忌**。  
    β遮断薬との併用も **徐脈・房室ブロック注意**。

## 3. 利尿薬（**青系**）

### サイアザイド系 { .rx-card .thiazide }

<span class="rx thiazide">サイアザイド</span>

| 項目 | 内容 |
|---|---|
| 代表薬 | ヒドロクロロチアジド (HCTZ) / トリクロルメチアジド (フルイトラン) / インダパミド (ナトリックス) |
| 機序 | 遠位尿細管 Na-Cl 共輸送阻害 |
| 強い適応 | 食塩感受性高血圧（高齢者）、骨粗鬆症合併（Ca保持） |
| 用量 | 少量で十分降圧 (HCTZ <span class="key-num">12.5 mg</span>, トリクロルメチアジド <span class="key-num">1 mg</span>) |

!!! mnemonic "覚え方 — サイアザイドの副作用『高い／低い』"
    **高い**: 尿酸 / 血糖 / Ca / Lipid  
    **低い**: K / Na / Mg  
    （4高3低）

### ループ利尿薬 { .rx-card .loop }

<span class="rx loop">ループ</span>

降圧目的より **体液管理 / 心不全 / 腎機能低下例** で使用。

- フロセミド (ラシックス) / アゾセミド (ダイアート) / トラセミド (ルプラック)
- **eGFR < 30** ではサイアザイドが効きにくくなりループへ切替

### MRA（ミネラルコルチコイド受容体拮抗薬） { .rx-card .mra }

<span class="rx mra">MRA</span>

| 薬剤 | 特徴 |
|---|---|
| スピロノラクトン (アルダクトン A) | 非選択的、**女性化乳房** |
| エプレレノン (セララ) | 選択的、女性化乳房少ない |
| エサキセレノン (ミネブロ) | 非ステロイド型、本邦の高血圧適応 |
| フィネレノン (ケレンディア) | 非ステロイド型、**DM合併 CKD** で心腎保護 |

**強い適応**: 治療抵抗性高血圧（3剤併用でもコントロール不良）、原発性アルドステロン症、HFrEF。

!!! pitfall "K と腎の監視"
    K 上昇・腎機能悪化に注意。**eGFR < 30 や K > 5.0** では慎重投与。

## 4. β遮断薬（**橙**）

<span class="rx beta">β遮断</span>

| 区分 | 代表薬 | 特徴 |
|---|---|---|
| β1選択性 | ビソプロロール (メインテート) / メトプロロール (セロケン) | 心保護メイン |
| α/β | カルベジロール (アーチスト) | HFrEF、血管拡張も |
| 非選択性 | プロプラノロール (インデラル) | 甲状腺・本態性振戦 |

**強い適応**: HFrEF（ビソプロロール / カルベジロール）、冠動脈疾患、頻拍合併、大動脈解離、甲状腺中毒症。

!!! pitfall "急な中止 = 反跳"
    **急な中止で離脱症状**（反跳性頻拍・血圧上昇・狭心症）。減量で対応する。

!!! mnemonic "覚え方 — βの注意 『心ぜん肝糖』"
    **心**: 急性非代償性HF・徐脈で導入控え  
    **ぜん（喘息）**: 非選択は禁忌  
    **肝**: カルベジロールは肝代謝  
    **糖**: 低血糖症状をマスク

## 5. α遮断薬（**薄紫**）

<span class="rx alpha">α遮断</span>

- ドキサゾシン (カルデナリン) / テラゾシン
- **適応**: 前立腺肥大症合併、褐色細胞腫の術前
- **注意**: 起立性低血圧（**初回投与・夜間** が要注意）、ALLHAT で心不全リスク↑ → first line にしない

## 6. 中枢性・その他

<span class="rx central">中枢性</span> <span class="rx vasodil">血管拡張</span>

- メチルドパ (アルドメット) → **妊娠高血圧症で安全に使える数少ない薬**
- クロニジン (カタプレス) → 中枢性 α2 作動。反跳性高血圧注意
- ヒドララジン → 妊娠高血圧 / 治療抵抗性
