# AMI（急性心筋梗塞）救急外来 初期対応

!!! warning "免責"
    用量は代表例です。適応・禁忌・投与量は最新の **JCS / ACC-AHA / ESC ガイドラインと添付文書** を必ずご確認ください。特に **プラスグレルの負荷量は本邦と海外で大きく異なります**。

胸痛・冷汗・呼吸苦で「ACSかも」と思った瞬間から動く。<span class="rx danger">最優先</span> は **10分以内の12誘導心電図** と、STEMIなら **door-to-balloon &lt;90分**。

!!! mnemonic "動き出しの合言葉"
    **MONA より再灌流が命。**「時計を回し始めるのは“疑った瞬間”」。
    Door-to-ECG <span class="key-num">&lt;10分</span> / Door-to-balloon <span class="key-num">&lt;90分</span>（搬送例 &lt;120分）。

## STEP 1 — 初期評価・蘇生準備（来院〜数分）

- **ABC確認・モニター装着**: SpO₂・血圧・心電図モニター・除細動器をベッドサイドへ。
- **静脈路 ×2 / 採血**: トロポニン・CK-MB・生化・血算・凝固・血糖。
- **酸素**: <span class="key-num">SpO₂ &lt;90%</span> または呼吸苦・心不全徴候のときのみ。ルーチン投与はしない。
- **身体所見**: 末梢冷感・頸静脈怒張・ラ音・心雑音・左右の血圧差を素早く。
- 同時並行で **12誘導心電図** をオーダー（STEP 2）。

!!! pitfall "Killer chest pain を同時に否定"
    大動脈解離（血圧左右差・背部痛・縦隔拡大）／肺塞栓／緊張性気胸／食道破裂。
    **解離を疑うなら抗血小板・抗凝固の前に止まる。**

## STEP 2 — 12誘導心電図 → STEMI判定（来院10分以内）

- **ST上昇**: 連続する2誘導で。肢誘導 ≧1mm／胸部 V2-V3 は男性≧2mm・女性≧1.5mm・その他≧1mm。
- 新規 **LBBB**／ペーシング波形 → STEMI相当として扱う（Sgarbossa基準）。
- **下壁梗塞（II・III・aVF）** では必ず **右側胸部誘導（V3R-V4R）・背側誘導（V7-V9）** を追加 → 右室・後壁梗塞の検出。
- **aVR上昇 + 広範囲ST低下** → 左主幹部／三枝病変を示唆（高リスク）。
- 変化なくても胸痛持続なら <span class="key-num">15〜30分ごと</span> に再検。

!!! pearl "STEMIと判定したら、ここで循環器／カテ室へ即コール"
    薬剤準備と並行して動く。Door-to-balloon &lt;90分（搬送例 &lt;120分）。

## STEP 3 — 初期薬物治療（STEMI / NSTEMI 共通の土台）

| 薬剤 | 用法・用量 | 注意 |
|---|---|---|
| <span class="rx aspirin">ASA</span> アスピリン | 162〜325mg（本邦 **200mg**）咀嚼 | 禁忌なければ全例・最速。腸溶錠でも噛み砕く |
| <span class="rx p2y12">P2Y12</span> プラスグレル | 負荷 **20mg** → 維持 3.75mg/日（本邦PCI用量） | 体重&lt;50kg・75歳以上・脳卒中既往は要注意。海外用量と異なる |
| <span class="rx p2y12">P2Y12</span> クロピドグレル | 負荷 300mg(〜600mg) → 維持 75mg/日 | 線溶併用時や効果発現を急がない場合 |
| <span class="rx heparin">UFH</span> 未分画ヘパリン | PCI時 60〜100単位/kg 静注（ACT目標で調整） | 再灌流戦略に合わせ循環器と調整 |
| <span class="rx vasodil">NTG</span> 硝酸薬 | 下記カード参照 | 下壁/右室梗塞・SBP&lt;90・PDE5阻害薬使用は **禁忌** |
| <span class="rx caution">麻薬</span> モルヒネ | 2〜4mg 静注、必要時 5〜15分ごと追加 | 過量で低血圧・呼吸抑制・抗血小板薬の吸収遅延 |
| <span class="rx beta">βB</span> β遮断薬 | 禁忌なければ24時間以内に経口開始 | 心不全・低血圧・徐脈・ショック徴候では急性期に静注しない |
| <span class="rx statin">統</span> スタチン | 高強度を早期から（例 アトルバスタチン） | 急性期から導入 |

### 硝酸薬（ニトログリセリン）の使い方 { .rx-card .vw-iv }

<span class="rx vasodil">NTG</span>

- **① 舌下／スプレー（まず痛みに）**: ニトログリセリン舌下錠 0.3〜0.6mg または スプレー1噴霧。胸痛持続なら <span class="key-num">5分ごと最大3回</span> まで反復。各回前に血圧確認。
- **② 持続静注（痛み遷延・高血圧・心不全/肺水腫）**: <span class="key-num">0.5〜1.0 µg/kg/min</span> で開始 → 胸痛・血圧をみて 5〜10µg/min ずつ漸増。**SBP &lt;90〜100 mmHg、または前値から30mmHg以上低下したら減量・中止。**

!!! pitfall "硝酸薬を絶対に使わない場面"
    **右室梗塞／下壁梗塞で前負荷依存・低血圧（SBP&lt;90）・高度徐脈/頻脈・PDE5阻害薬（シルデナフィル等24時間以内/タダラフィル48時間以内）使用後。**

!!! pitfall "右室梗塞を疑うとき"
    硝酸薬・モルヒネで一気に前負荷が落ちて **ショック** に。
    まず **生理食塩水 200〜500mL を急速輸液** で血圧を支えてから判断。

## STEP 4 — 再灌流療法の決定

=== "STEMI（ST上昇）"

    - <span class="rx first">第一選択</span> **緊急PCI** → 即カテ室。
    - 発症 ≦12時間が最大の適応。胸痛・心不全持続なら12時間超でも検討。
    - PCI不可施設: 90〜120分以内に転送できなければ **線溶療法** を考慮（禁忌確認）。
    - 心原性ショック／致死性不整脈 → 緊急で循環器・ICU・補助循環の準備。

=== "NSTEMI / UA（ST上昇なし）"

    - トロポニン・症状・心電図変化でリスク層別化（GRACE等）。
    - **超高リスク**（血行動態不安定・難治性胸痛・致死性不整脈・機械的合併症）→ <span class="key-num">2時間以内</span> の侵襲的戦略。
    - 高リスク → 24時間以内のPCI。
    - 原則、緊急線溶療法は行わない。

## STEP 5 — 合併症の監視・搬送まで

- <span class="rx danger">VF/VT</span> 除細動器を即使える状態に。ACLSアルゴリズム。
- <span class="rx danger">徐脈/AVB</span>（特に下壁）: アトロピン 0.5mg静注（反復、最大3mg）、経皮ペーシング準備。
- <span class="rx danger">心原性ショック</span>: ノルアドレナリン等で昇圧、補助循環（IABP/IMPELLA/VA-ECMO）の早期相談。
- **機械的合併症**: 心室中隔穿孔・乳頭筋断裂・自由壁破裂 → 新規雑音/急変で疑い心エコー。
- **急性心不全・肺水腫**: 硝酸薬・利尿薬（フロセミド）・NPPV。
- 引き継ぎ: 心電図経時変化・投与薬・時刻・アレルギー・抗血小板内服歴を申し送り。

## 落とし穴 / 忘れがち

!!! pitfall "見落としやすいポイント"
    - 初回心電図が正常でも除外できない → **繰り返し記録** ＋ トロポニン経時。
    - 高齢者・女性・糖尿病は **非典型症状**（息切れ・嘔気・倦怠・心窩部痛）。
    - 下壁STEMIで安易な硝酸薬 → 右室梗塞だと血圧が落ちる。
    - 大動脈解離を否定せず抗血栓薬を入れない。
    - 「door-to-ECG 10分 / door-to-balloon 90分」の **時計を回し始めるのは“疑った瞬間”**。

---

*STEMI = ST上昇型心筋梗塞 / NSTEMI = 非ST上昇型 / UA = 不安定狭心症 / DTB = door-to-balloon*
