# 抗菌薬まとめ（市中感染症 — 肺炎・尿路感染中心）

!!! warning "免責"
    本ページは個人の学習メモです。投与量・適応・腎機能補正・地域感受性は **添付文書・JAID/JSC 感染症治療ガイドライン・施設のアンチバイオグラム** を必ずご確認ください。

## 大原則（empiric therapy）

1. **培養を取ってから抗菌薬**（血液・尿・喀痰など）。投与開始まで遅らせない範囲で。
2. **狭域 ＞ 広域**。グラム染色 + 部位 + 重症度 + 患者背景（免疫・基礎疾患・MDR リスク）で選ぶ。
3. 48–72時間で **培養とレスポンスを見て de-escalation**。
4. **適切な期間で止める**（長すぎても短すぎても害）。
5. アレルギー歴は「副作用」と「真のアレルギー」を区別して聴取。

## 主要クラスのおさらい

### ペニシリン系

| 薬 | カバー | 用途 |
|---|---|---|
| ベンジルペニシリン (PCG) | 連鎖球菌・髄膜炎菌・梅毒・嫌気性（口腔内） | 肺炎球菌肺炎・心内膜炎（感受性確認後） |
| アンピシリン (ABPC) / アモキシシリン (AMPC) | + Listeria, 一部 H. influenzae, E. coli (感受性低下) | 軽症 UTI・咽頭炎・Listeria 髄膜炎 |
| ピペラシリン (PIPC) | + 緑膿菌 | 院内感染（PIPC/TAZ で広く使う） |

### βラクタマーゼ阻害剤配合

| 薬 | 特徴 |
|---|---|
| **アモキシシリン/クラブラン酸 (AMPC/CVA, オーグメンチン)** | 外来でとても重宝。**本邦は CVA 量が少ない比率** → 「AMPC を上乗せ」する慣習あり（AMPC 250mg+CVA 配合錠 + AMPC 250mg 追加） |
| **スルバクタム/アンピシリン (SBT/ABPC, ユナシン)** | 入院 CAP / 誤嚥性肺炎の定番 |
| **タゾバクタム/ピペラシリン (TAZ/PIPC, ゾシン)** | 緑膿菌カバー含む広域、院内・重症 |

### セフェム系（世代）

| 世代 | 代表 | カバー |
|---|---|---|
| 1 | セファゾリン (CEZ) iv / セファレキシン (CEX) po | GP 球菌、皮膚軟部、術前予防 |
| 2 | セフメタゾール (CMZ) | 嫌気性カバー、ESBL産生菌の一部に有効 |
| 3 | セフトリアキソン (CTRX) / セフォタキシム (CTX) | 髄膜炎・市中肺炎・腎盂腎炎・淋菌 |
| 3 (抗緑膿菌) | セフタジジム (CAZ) | 緑膿菌 ◯、GP は弱め |
| 4 | セフェピム (CFPM) | 緑膿菌＋GP も保つ、発熱性好中球減少症 |
| 経口 3 | セフジトレン (CDTR-PI), セフカペン (CFPN-PI) | **吸収率が低く** 過大評価しないこと |

!!! warning "経口セフェムの落とし穴"
    第3世代経口セフェムはバイオアベイラビリティが低く、組織移行も乏しい。**腎盂腎炎・菌血症** には不適。市中の軽症膀胱炎などに限定。

### カルバペネム

- メロペネム (MEPM) / イミペネム (IPM/CS) / ドリペネム / エルタペネム
- ESBL産生菌・重症複雑性感染症で使用。**温存** が原則（耐性誘導）。

### マクロライド

- アジスロマイシン (AZM) / クラリスロマイシン (CAM) / エリスロマイシン
- **非定型** カバー（マイコプラズマ・クラミドフィラ・レジオネラ）
- 心電図 **QT延長** に注意、薬物相互作用多い (CYP3A4)

### キノロン (フルオロキノロン)

| グループ | 薬 | 特徴 |
|---|---|---|
| レスピラトリー | レボフロキサシン (LVFX), モキシフロキサシン (MFLX), シタフロキサシン (STFX), ガレノキサシン | 肺炎球菌＋非定型カバー |
| 抗緑膿菌 | シプロフロキサシン (CPFX), LVFX 高用量 | UTI・腸内・緑膿菌 |

**注意**:
- **腱断裂・大動脈解離・QT延長・低血糖・末梢神経障害・C. difficile**
- 妊婦・小児・てんかんは原則回避
- **結核を見逃すリスク** → CAP に安易に出さない（培養陰性化させてしまう）

### その他

| 薬 | 用途・特徴 |
|---|---|
| ST合剤 (TMP/SMX, バクタ) | UTI、PCP、MRSA SSTI。**高K・腎機能↓・皮疹・血液障害** |
| ホスホマイシン (FOM) | 単純性膀胱炎の単回投与 |
| メトロニダゾール (MNZ) | 嫌気性・CDI・トリコモナス・アメーバ。**飲酒禁** |
| クリンダマイシン (CLDM) | GP・嫌気性（横隔膜上）。CDI リスク高 |
| バンコマイシン (VCM) | MRSA、ペニシリンアレルギーの GP。TDM 必須 |
| リネゾリド (LZD) | MRSA、VRE。骨髄抑制・乳酸アシドーシス |
| テトラサイクリン系 (DOXY, MINO) | 非定型、ライム、リケッチア、ニキビ |

## 市中肺炎 (CAP)

### 重症度評価（外来 vs 入院判断）

**A-DROP**（日本呼吸器学会）

| 項目 | 内容 |
|---|---|
| A | Age 男 ≥70, 女 ≥75 |
| D | Dehydration BUN ≥21 mg/dL |
| R | Respiration SpO₂ ≤90% (PaO₂ ≤60) |
| O | Orientation 意識障害 |
| P | Pressure 収縮期 ≤90 mmHg |

- 0点: 外来
- 1–2点: 外来または入院
- 3点: 入院、4–5点: ICU検討

**CURB-65** や **PSI** も併用可。

### 主な原因菌

| 状況 | 想定起炎菌 |
|---|---|
| 外来・軽症 | 肺炎球菌、マイコプラズマ、クラミドフィラ |
| 入院（一般病棟） | 肺炎球菌、インフルエンザ桿菌、モラクセラ、レジオネラ、非定型、ウイルス |
| 重症・ICU | 肺炎球菌、レジオネラ、黄色ブドウ球菌（インフルエンザ後）、緑膿菌（構造的肺疾患） |
| 誤嚥性 | 口腔内嫌気性 + GN桿菌 |

### Empiric 治療

#### 外来（軽症・健常）

| 想定 | 第一選択 |
|---|---|
| 定型菌中心（肺炎球菌など） | **AMPC 高用量** 1500–2000 mg/日 分3 ± マクロライド |
| 非定型疑い（若年・乾性咳・徐脈） | アジスロマイシン or クラリスロマイシン or DOXY |
| 重複カバー希望・基礎疾患あり | レスピラトリーキノロン（**結核除外後**） |

#### 入院（一般病棟）

- **SBT/ABPC (ユナシン) 3 g × 3–4回/日 iv** ± **アジスロマイシン iv**
- または **CTRX 1–2 g/日 iv** ± マクロライド
- ペニシリンアレルギー: レスピラトリーキノロン

#### 重症 / ICU

- **CTRX (or SBT/ABPC) + アジスロマイシン or レスピラトリーキノロン**
- **構造的肺疾患・最近の抗菌薬使用** → 緑膿菌カバー (PIPC/TAZ, CFPM)
- **インフルエンザ後・壊死性肺炎・MRSA リスク** → VCM or LZD 追加

#### 誤嚥性肺炎

- **SBT/ABPC** が定番。
- 重症・耐性懸念: PIPC/TAZ
- **メトロニダゾール追加は通常不要**（SBT/ABPC で嫌気カバー十分）

!!! tip "尿中抗原"
    肺炎球菌・レジオネラ尿中抗原は **入院時のルーチン**。レジオネラが陽性ならキノロン or アジスロマイシン、肺炎球菌陽性ならペニシリン系に絞り込みやすい。

### 治療期間

| 状況 | 期間 |
|---|---|
| 軽症 CAP（適切に応答） | **5日間**で十分（解熱後48–72hで継続不要） |
| 中等症〜重症 | 7日間 |
| レジオネラ | 7–14日（重症は 21日） |
| 黄色ブドウ球菌・緑膿菌 | 14日以上を考慮 |

### NHCAP / 院内肺炎は別アルゴリズム

NHCAP（医療・介護関連肺炎）は CAP より耐性菌リスクが高い場合があり、患者背景と施設アンチバイオグラムでカバー幅を決める（本ページは市中中心なので割愛）。

## 尿路感染症 (UTI)

### 分類

| 区分 | 定義 |
|---|---|
| **単純性** UTI | 健常 **非妊娠成人女性** の急性膀胱炎・腎盂腎炎 |
| **複雑性** UTI | 男性 / 妊婦 / 尿路異常 / カテーテル / 免疫不全 / 糖尿病コントロール不良 / 最近の入院・抗菌薬曝露 |

### 主な原因菌

- **大腸菌 (E. coli) が圧倒的多数**（70–80%）
- その他: K. pneumoniae, Proteus, S. saprophyticus（性活発な女性）、Enterococcus
- **施設の E. coli の感受性** （ESBL・キノロン耐性率）を必ず確認

### 急性単純性膀胱炎（成人女性）

| 第一選択 | 用量 |
|---|---|
| **ホスホマイシン (FOM) 経口** | 3 g 単回（本邦は 1 g × 3日/日 × 2 などの分割もあり） |
| **ST合剤 (バクタ)** | 2錠 × 2/日 × 3日。感受性 ≥80% が前提 |
| **CCL (セファクロル) や CDTR-PI** | 3–5日。耐性少なめだが組織移行は弱 |
| **キノロン (LVFX 等)** | **温存**。他薬使えない時のみ |

- **培養は通常不要**（典型症状の若年女性）
- 再発時・治療失敗時は培養

### 急性腎盂腎炎（単純性）

| 重症度 | 治療 |
|---|---|
| 軽症・経口可・脱水なし | **LVFX 500 mg/日** 7日 or **ST合剤** 14日（感受性確認） |
| 中等症以上・吐気あり・入院 | **CTRX 1–2 g/日 iv** 7–14日、解熱後経口スイッチ |
| ESBL リスク（既往・最近のセフェム曝露） | CMZ または カルバペネム（感受性で de-escalation） |

!!! tip
    腎盂腎炎は **必ず尿培養 + 血液培養** を採取してから抗菌薬。経口セフェム第3世代は **不適**（吸収・組織移行が弱い）。

### 男性 UTI

- 解剖学的・前立腺関与で **複雑性扱い**。
- 急性前立腺炎: **LVFX または ST合剤** 2–4週（前立腺移行良好な薬を選ぶ）
- 慢性前立腺炎: 4–6週

### 妊婦

- **無症候性細菌尿も治療** する（早産・腎盂腎炎リスク）
- 第一選択: **セファレキシン**、AMPC、ホスホマイシン（妊娠中後期は注意）
- **キノロン・ST合剤（特に妊娠初期と分娩前）は回避**

### カテーテル関連 UTI (CA-UTI)

- **無症候性細菌尿は治療しない**（カテーテル抜去/交換だけで十分なことが多い）
- 症状あれば培養 + empiric 治療、カテーテル交換 / 抜去

### 治療期間まとめ

| 病態 | 期間 |
|---|---|
| 単純性膀胱炎 | 3日（FOMは単回） |
| 単純性腎盂腎炎 (キノロン) | 5–7日 |
| 単純性腎盂腎炎 (βラクタム/ST) | 10–14日 |
| 複雑性 UTI | 7–14日（病態次第） |
| 急性前立腺炎 | 2–4週 |

## その他よく遭遇する市中感染症（簡潔に）

### 急性気管支炎・上気道炎

- **ウイルス性が大半 → 抗菌薬は基本不要**
- 例外: 百日咳（マクロライド）、A群溶連菌咽頭炎（AMPC 10日）

### 急性副鼻腔炎

- 細菌性の疑い（10日以上持続・二峰性・重症）なら AMPC 高用量 ± クラブラン酸 5–7日

### 中耳炎（小児）

- AMPC 高用量。耐性肺炎球菌や難治例で AMPC/CVA

### 蜂窩織炎（化膿なし）

- A群溶連菌・黄色ブドウ球菌が主体
- 軽症: セファレキシン経口 5–7日
- 重症: セファゾリン iv

### MRSA SSTI（膿瘍・市中 MRSA リスク）

- ドレナージ + ST合剤 or DOXY or クリンダマイシン

### 急性腸炎

- **ウイルス・自然軽快が多い → 抗菌薬不要が原則**
- 重症・血便・高熱・免疫不全例: AZM or CPFX（カンピロ・サルモネラ・赤痢 など想定）
- **EHEC を疑う血便はキノロン投与を慎重に**（HUS 誘発の懸念）

### 偽膜性大腸炎 (CDI)

- 軽症〜中等症: **経口バンコマイシン 125 mg × 4/日 10日** が第一選択（メトロニダゾールは劣る）
- 重症・劇症: VCM + メトロニダゾール iv ± フィダキソマイシン

## ペニシリンアレルギーの判別

| 病歴 | 対応 |
|---|---|
| 即時型（蕁麻疹・アナフィラキシー・喉頭浮腫） | βラクタム回避、必要なら脱感作・他系統 |
| 非即時型・遅延型（軽度皮疹のみ） | **真のIgE型でないことが多い**、セフェムは交差反応 <1–2% |
| 「子供のときに薬で発疹が出た」程度 | 可能なら詳細聴取、βラクタム使えることが多い |
| カルバペネム | ペニシリンとの交差反応はごく低い (<1%) |

## 注意したい副作用・合併症

- **C. difficile 感染症 (CDI)**: ほぼ全ての抗菌薬で誘発、特に **クリンダマイシン・キノロン・第3〜4世代セフェム**
- **QT延長 → TdP**: マクロライド・キノロン（特に + 抗不整脈薬・電解質異常）
- **腱断裂・大動脈解離**: キノロン
- **腎障害**: VCM, アミノグリコシド, ST合剤（高用量）
- **薬疹（DRESS, SJS, TEN）**: ST合剤・βラクタム・バンコマイシン
- **菌交代症・カンジダ症**: 長期広域抗菌薬
