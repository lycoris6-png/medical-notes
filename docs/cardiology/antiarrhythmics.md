# 抗不整脈薬まとめ

!!! warning "免責"
    投与量・適応・QT延長など重要な注意点は、最新の **添付文書・JCSガイドライン** を必ずご確認ください。

## Vaughan-Williams クラス早見（色で覚える）

<span class="rx vw-ia">Ia</span> Na↓中等 + K↓（APD延長）  
<span class="rx vw-ib">Ib</span> Na↓弱（APD短縮）  
<span class="rx vw-ic">Ic</span> Na↓強（APD変化少）  
<span class="rx vw-ii">II</span> β遮断  
<span class="rx vw-iii">III</span> K↓（APD延長）  
<span class="rx vw-iv">IV</span> 非DHP Ca

!!! mnemonic "覚え方 — クラス I のサブ分類「Iaは中間、Ibは短く、Icは強く」"
    APD で覚える: **Ia 中間延長 / Ib 短縮 / Ic 不変**。  
    別の覚え方 — Na↓の強さ: **Ic > Ia > Ib**（Cがいちばん強くブロック）。

## Vaughan-Williams 分類

| クラス | 主な機序 | 代表薬 |
|---|---|---|
| <span class="rx vw-ia">Ia</span> | Na↓中等 + K↓ | プロカインアミド、ジソピラミド、シベンゾリン |
| <span class="rx vw-ib">Ib</span> | Na↓弱（APD短縮） | リドカイン、メキシレチン |
| <span class="rx vw-ic">Ic</span> | Na↓強（APD不変） | フレカイニド、ピルシカイニド、プロパフェノン |
| <span class="rx vw-ii">II</span> | β遮断 | プロプラノロール、ビソプロロール、ランジオロール |
| <span class="rx vw-iii">III</span> | K↓（APD延長） | アミオダロン、ソタロール、ニフェカラント、ベプリジル |
| <span class="rx vw-iv">IV</span> | 非DHP Ca | ベラパミル、ジルチアゼム |
| <span class="rx vw-other">他</span> | — | ジゴキシン、アデノシン、アトロピン、イバブラジン |

!!! tip "Sicilian Gambit"
    実臨床では Vaughan-Williams は粗い。チャネル特異性・状態依存性・自律神経作用まで含めた Sicilian Gambit のほうが薬剤選択の議論に向く。

## クラス別の使いどころ

### Class Ia — プロカインアミド / ジソピラミド / シベンゾリン { .rx-card .vw-ia }

<span class="rx vw-ia">Ia</span>

- **用途**: AF の薬理学的除細動、頻拍源不明。実臨床では Ic / III に押されあまり使われない。
- **注意**: 抗コリン作用（口渇・尿閉）、QT延長、陰性変力。
- **特殊**: HOCM ではジソピラミドが LVOT 圧較差を下げる目的で有用。

### Class Ib — リドカイン / メキシレチン { .rx-card .vw-ib }

<span class="rx vw-ib">Ib</span>

- **リドカイン (iv)**: 心室性不整脈、特に虚血由来 VT/VF。ACLS では第二選択（アミオダロンに次ぐ）。
- **メキシレチン (po)**: 心室性期外収縮、慢性 VT。糖尿病性神経障害痛にも。
- **注意**: 中枢神経症状（振戦・痙攣）、肝代謝。

### Class Ic — フレカイニド / ピルシカイニド / プロパフェノン { .rx-card .vw-ic }

<span class="rx vw-ic">Ic</span>

- **用途**: **構造的心疾患のない** AF / SVT の薬理学的除細動 ("pill in the pocket")、洞調律維持。

!!! pitfall "Ic 禁忌 — 虚血・心不全"
    虚血・心不全・著明な左室肥大では **CAST 試験で死亡率↑**。器質的心疾患があれば Ic は使わない。

!!! pearl "Ic を出すなら房室抑制をセットで"
    Ic は心房粗動を 1:1 房室伝導させ得る → 心室レート爆上がり。  
    **必ず <span class="rx beta">β</span> または <span class="rx ca-ndhp">非DHP Ca</span> を併用** して房室抑制。

### Class II — β遮断薬 { .rx-card .vw-ii }

<span class="rx vw-ii">II</span>

- **用途**: AF / AFL の rate control、運動誘発性 VT、QT延長症候群、ACS、HFrEF。
- 急性期は **ランジオロール (オノアクト)** が短時間作用で重宝。

### Class III — アミオダロン他 { .rx-card .vw-iii }

<span class="rx vw-iii">III</span>

#### アミオダロン (アンカロン)

| 項目 | 内容 |
|---|---|
| 特徴 | I/II/III/IV のすべての作用、効果強力、**陰性変力少なめ** |
| 用途 | VT/VF（特に器質的心疾患・心不全合併）、AF洞調律維持 |
| 静注 | ACLS の VF/pulseless VT 第一選択（<span class="key-num">300 mg → 150 mg</span>） |
| 経口 | 維持量 100–200 mg/日（負荷後） |
| 副作用 | **肺線維症 / 甲状腺異常 / 肝障害 / 角膜沈着 / 皮膚色素沈着** |

!!! mnemonic "アミオダロン副作用 — 『肺・甲・肝・目・皮』"
    **肺**線維症 / **甲**状腺機能異常（亢進も低下も） / **肝**障害 / 角膜 = **目** / **皮**膚色素沈着。  
    開始時 + 半年毎: TSH/FT4・肝機能・胸部 X 線・眼科。

#### ソタロール / ニフェカラント / ベプリジル

- **ソタロール**: β + III。AF洞調律維持・VT。**QT延長 → TdP**、腎排泄で減量。
- **ニフェカラント (シンビット)**: 静注のみ。VF/VT レスキュー。QT 注意。
- **ベプリジル (ベプリコール)**: 多面作用、持続性 AF の洞調律維持。**TdP 慎重**。

### Class IV — 非DHP Ca { .rx-card .vw-iv }

<span class="rx vw-iv">IV</span>

- **用途**: 上室性頻拍 (SVT) の停止・予防、AF / AFL の rate control。
- **禁忌**: <span class="rx danger">HFrEF</span> <span class="rx danger">WPW + AF</span> <span class="rx danger">高度AVブロック</span>。

### その他

<span class="rx vw-other">その他</span>

- **アデノシン (アデホス) iv bolus**: PSVT 停止。半減期 10秒未満で速い。喘息注意。
- **ジゴキシン**: AF rate control（HF合併）。狭い治療域、腎排泄、**低K で中毒↑**。
- **イバブラジン (コララン)**: HFrEF + 洞調律 + HR ≥ 75 で β最大量でも頻拍残る場合の補助。**AF には無効**。
- **アトロピン**: 症候性徐脈、迷走神経反射性徐脈。

## 不整脈別の薬剤選択ざっくり

### 心房細動 (AF)

| 局面 | 第一選択 |
|---|---|
| Rate control（安定時） | <span class="rx beta">β</span> or <span class="rx ca-ndhp">非DHP Ca</span> |
| Rate control（HFrEF） | <span class="rx beta">β</span>（± ジゴキシン）。**<span class="rx ca-ndhp">非DHP Ca</span> は禁忌** |
| 緊急 rate control | ランジオロール / ジルチアゼム iv |
| Rhythm control（構造正常） | <span class="rx vw-ic">Ic</span> フレカイニド / ピルシカイニド / プロパフェノン |
| Rhythm control（器質的） | <span class="rx vw-iii">III</span> アミオダロン / ソタロール / ベプリジル |
| 洞調律維持（長期） | カテーテルアブレーション >> 薬剤 |

### 上室性頻拍 (SVT, AVNRT/AVRT)

- 急性: 迷走神経刺激 → **アデノシン iv** → <span class="rx beta">β</span> or <span class="rx ca-ndhp">非DHP Ca</span> iv
- 慢性: アブレーションが第一選択

### WPW + AF（pre-excited AF）

!!! pitfall "絶対禁忌 — 「ABCD」"
    **A**denosine / **B**eta-blocker / **C**alcium (非DHP) / **D**igoxin。  
    副伝導路への伝導を促進し VF を誘発し得る。
    急性期は **プロカインアミド** または **同期下電気的除細動**。

### 心室頻拍 / 心室細動

| 局面 | 第一選択 |
|---|---|
| 蘇生中 (VF/pulseless VT) | 電気的除細動 + アミオダロン iv（または リドカイン） |
| 安定 monomorphic VT | アミオダロン / プロカインアミド / リドカイン iv |
| **多形性 VT（QT延長）** | <span class="rx caution">Mg iv</span> + 原因薬剤中止 + K/Mg 補正 + ペーシング |
| 慢性予防 | 構造的心疾患 + 高リスク → **ICD**、薬剤は補助 |

## QT延長・TdP の覚え方

!!! mnemonic "QT延長で TdP を起こしやすい薬たち"
    **A**ntiarrhythmics: <span class="rx vw-ia">Ia</span> <span class="rx vw-iii">III</span>（アミオ・ソタ・ニフェ・ベプリ）  
    **A**ntibiotics: マクロライド・キノロン  
    **A**ntipsychotics: ハロペリドール・ジプラシドン  
    **A**ntidepressants: TCA・シタロプラム  
    **A**ntiemetics: オンダンセトロン  
    リスク因子: 低 K / 低 Mg / 徐脈 / 女性 / 心疾患

## 特に怖い相互作用・副作用

- **QT延長**: 上記まとめ参照
- **Brugada 様 ST変化**: <span class="rx vw-ic">Ic</span>、特にピルシカイニドは診断的にも用いられる
- **薬剤誘発性 AV ブロック**: <span class="rx beta">β</span> + <span class="rx ca-ndhp">非DHP Ca</span> の併用、ジゴキシン高用量
- **アミオダロン肺**: 咳・労作時呼吸困難 → HRCT
- **甲状腺**: アミオダロンは I含有量多く、亢進にも低下にも傾く
