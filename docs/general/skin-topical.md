# 入院患者の皮膚障害 — 外用薬と薬疹緊急対応

!!! warning "免責"
    用量・ランク・適応は代表例です。最終判断は最新のガイドライン・添付文書、および皮膚科コンサルトに従ってください。重症薬疹（SJS/TEN/DIHS）を疑う場合は速やかに皮膚科へ。

入院中に病棟でよく遭遇する皮膚トラブルへの外用対応と、見逃すと致命的になりうる**薬疹の初期対応**をまとめる。原則は「**感染を除外 → 適切なランクの外用 → 重症薬疹のサインを見逃さない**」。

## ステロイド外用薬のランク（5段階）

!!! mnemonic "強さの順（弱→強）"
    **Weak ＜ Medium/Mild ＜ Strong ＜ Very strong ＜ Strongest**（I群が最強）

| ランク | 代表薬（一般名） | 主な使いどころ |
|---|---|---|
| <span class="rx danger">I 最強</span> Strongest | クロベタゾールプロピオン酸エステル、ジフロラゾン酢酸エステル | 難治・苔癬化した手掌足底など |
| <span class="rx caution">II 非常に強い</span> Very strong | モメタゾン、ベタメタゾン酪酸エステルプロピオン酸エステル、ジフルプレドナート | 体幹四肢の強い炎症 |
| <span class="rx beta">III 強い</span> Strong | ベタメタゾン吉草酸エステル、デキサメタゾンプロピオン酸エステル | 体幹四肢の一般的な湿疹 |
| <span class="rx vasodil">IV 中等度</span> Medium | プレドニゾロン吉草酸エステル酢酸エステル、トリアムシノロンアセトニド | 軽症体幹、**顔・頸部・間擦部** |
| <span class="rx statin">V 弱い</span> Weak | ヒドロコルチゾン酢酸エステル、プレドニゾロン | 乳児・ごく軽症 |

!!! pearl "部位で強さを変える"
    皮膚が薄く吸収率が高い部位（**顔・頸部・陰部・間擦部**）はランクを下げる。陰嚢は前腕の約42倍、頬は約13倍吸収する。逆に**手掌・足底**は分厚く、Strong以上が要る。

!!! pitfall "ステロイド外用の禁忌・注意"
    - **感染巣（細菌・真菌・ウイルス）が明らかな部位には単独で塗らない** — 増悪する。
    - 潰瘍・びらん・熱傷・凍傷面には原則使わない。
    - 顔の長期連用で酒さ様皮膚炎・皮膚萎縮。改善したらランクダウン・間欠塗布へ。

## 病棟でよくある皮膚障害と外用対応

=== "接触皮膚炎 / 湿疹・皮膚炎"

    テープ・消毒・ガーゼなどによるかぶれ、乾皮症からの湿疹。

    - 原因（テープ等）の除去がまず第一。
    - <span class="rx beta">III〜II</span> 体幹四肢：strong〜very strong のステロイド外用 1日1〜2回。
    - <span class="rx vasodil">IV</span> 顔・頸部：medium で短期。改善後は保湿へ移行。
    - 乾燥が背景なら**保湿（ヘパリン類似物質・白色ワセリン）**を併用・先行。

=== "皮脂欠乏 / 乾皮症・そう痒"

    高齢入院患者に非常に多い。冬季・利尿薬使用で悪化。

    - <span class="rx statin">保湿</span> ヘパリン類似物質ローション/クリーム、白色ワセリンを1日2回、入浴後すぐ。
    - 掻破による湿疹化があれば短期に <span class="rx vasodil">IV</span> medium ステロイド追加。
    - 掻痒に対し必要なら抗ヒスタミン薬内服を併用。

=== "失禁関連皮膚炎(IAD) / おむつ部"

    尿便の接触による刺激性皮膚炎。**真菌感染との鑑別が要**。

    - **皮膚保護**が主役：撥水性の**白色ワセリン・酸化亜鉛**で被覆、こまめな交換・清拭。
    - びらん面にステロイドは原則避ける。明らかな湿疹要素のみ短期・弱め。
    - 衛星病変・境界明瞭な紅斑があれば**カンジダを疑い抗真菌へ**（下タブ）。

=== "皮膚カンジダ / 白癬（間擦部・足）"

    間擦部（鼠径・腋窩・乳房下）の浸軟、衛星病変はカンジダを示唆。

    - <span class="rx p2y12">抗真菌</span> カンジダ：イミダゾール系（ミコナゾール、ケトコナゾール等）クリーム 1日1〜2回。
    - 足白癬・体部白癬：イミダゾール系/アリルアミン系（テルビナフィン等）外用。
    - **ステロイドとの混合・先行塗布で悪化（白癬の修飾）に注意。** 不明なら鏡検（KOH）。

=== "蕁麻疹 / 限局性そう痒"

    膨疹・一過性。外用より**全身管理**が中心。

    - 抗ヒスタミン薬内服が基本。外用ステロイドの効果は限定的。
    - **薬剤が原因のことがある** — 新規開始薬を確認。広範・粘膜・全身症状を伴えば薬疹を疑う（下記）。

# 薬疹発生時の緊急対応

!!! danger "まず疑う・止める"
    新規皮疹＋**発熱**を見たら薬疹を念頭に。**最も大切な初動は被疑薬を速やかに中止すること。** 重症型（SJS/TEN/DIHS）は致死的で、早期診断・早期治療が予後を決める。

## STEP 1 — 重症化のレッドフラグを確認

!!! pitfall "これがあれば重症薬疹（SJS/TEN）を強く疑う"
    - **粘膜疹**：眼（結膜充血・眼脂）、口唇・口腔のびらん、外陰部・肛門周囲のびらん。**眼症状はしばしば初発**。
    - **38℃以上の発熱**、全身倦怠。
    - **水疱・びらん・表皮剥離**、Nikolsky現象陽性（擦過で表皮が剥がれる）。
    - 紅斑が**急速に拡大・癒合**、疼痛を伴う。
    - 顔面・体幹優位の非隆起性紅斑で中央が暗紅色（標的様）。

!!! pearl "重症型の型を意識"
    - **SJS / TEN**：粘膜びらん＋表皮壊死。TENは表皮剥離が体表の広範囲（熱傷に準じた全身管理）。
    - **DIHS**：投与開始2〜6週後、発熱・顔面浮腫性紅斑・リンパ節腫脹・好酸球増多・肝障害。**HHV-6再活性化**。遅発性に経過。

## STEP 2 — 初期対応（病棟でやること）

- <span class="rx danger">最優先</span> **被疑薬を中止**（直近に開始・変更した薬すべてを洗い出す。抗菌薬・解熱鎮痛薬・アロプリノール・抗けいれん薬は高リスク）。
- バイタル・全身状態・体表面積に占める皮疹範囲・粘膜・眼を評価。
- 採血：血算（好酸球・白血球）、肝腎機能、CRP、電解質。必要に応じ各種ウイルス。
- <span class="rx danger">皮膚科を緊急コンサルト</span>。眼病変があれば**眼科も早期に**（眼後遺症予防）。
- 重症・進行例は**入院管理**（TENは熱傷に準じた補液・栄養・感染予防・体温管理）。

!!! warning "被疑薬の見極め"
    多剤併用例では「最後に増えた薬」「典型的な原因薬」「投与開始からの期間（SJS/TENは数日〜3週、DIHSは2〜6週）」から推定する。判断に迷っても**疑い薬の中止を遅らせない**。

## STEP 3 — 治療（皮膚科と連携、代表的指針）

| 病型 | 全身ステロイド | 補助療法 |
|---|---|---|
| <span class="rx danger">SJS/TEN</span> | 発症早期（**〜7日前後**）にプレドニゾロン換算 **1mg/kg/日前後**で開始、病勢をみて漸減 | 重症・急速進展・眼病変重症は**ステロイドパルス**。効果不十分なら **IVIg 400mg/kg/日×5日**、難治例に**血漿交換** |
| <span class="rx caution">DIHS</span> | プレドニゾロン換算 **0.5〜1mg/kg/日**で開始、**パルスは行わない**。初期量を1〜2週維持し緩徐に漸減 | CMV再活性化時は抗ウイルス薬。減量中の再燃・臓器障害に注意 |
| <span class="rx vasodil">軽症の播種状紅斑丘疹型</span> | 被疑薬中止＋経過観察。痒みに抗ヒスタミン薬、局所にステロイド外用 | 全身症状・粘膜・拡大傾向が出れば重症型として再評価 |

!!! pitfall "見逃し・落とし穴"
    - 「ただの発疹」で済ませない。**発熱・粘膜・水疱・疼痛**のどれかがあれば重症型を疑う。
    - DIHSは**被疑薬中止後もしばらく増悪**し、減量中に再燃しうる。経過が長い。
    - 原因薬は**再投与で重症化**。判明した被疑薬は確実にカルテ・お薬手帳へ記録し、患者へ説明。
    - 眼後遺症は不可逆になりうる — 眼症状を軽視しない。
